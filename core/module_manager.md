# Module Manager

Responsável pelo gerenciamento dos módulos do Master-Flow.

## Objetivo

Carregar e controlar módulos sem alterar o código interno dos projetos originais.

## Fluxo

1. Ler configuração dos módulos.
2. Verificar módulos habilitados.
3. Inicializar módulo solicitado.
4. Manter isolamento entre módulos.

Módulos previstos:
- automation-cloud
- master-ibo
